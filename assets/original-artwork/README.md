# Original Artwork

This directory is the canonical archive for original WORMS ON ACID artwork and source sketches.

- Preserve source files in their original form.
- Do not overwrite originals with edited, cropped, compressed, or web-optimised versions.
- Keep derivatives used by the website in the appropriate asset directories.
- Add a short note or filename convention when the character, scene, date, or source needs clarification.

Canonical artwork should be treated as the source of truth for future visual work.
