# Story Images

Store artwork created for WORMS ON ACID stories and scenes in this folder.

## Guidelines
- Keep story and scene illustrations here, separate from website UI assets and game-specific assets.
- Use the canonical character artwork in `/characters` as the source of truth for character appearance.
- Use descriptive, lowercase filenames with hyphens, for example `chapter-01-scene-01-scrapyard.webp`.
- Prefer optimized WebP for website illustrations; retain transparent PNGs when transparency is needed.
- Do not overwrite canonical character artwork with scene variations.
